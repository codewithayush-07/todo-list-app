# To-Do List App

A simple to-do list app I built with HTML, CSS, and JavaScript to
practice working with the DOM and browser storage.

The idea is to keep everyday tasks in one place and make it easy to see
what is finished and what still needs to be done.

## Features

-   Add new tasks
-   Mark tasks as completed
-   Edit or delete tasks
-   Keep tasks saved in the browser with `localStorage`
-   Use the app on desktop or mobile screens

## Built With

-   HTML5
-   CSS3
-   JavaScript
-   Browser `localStorage`

## Getting Started

You don't need to install any packages to run this project.

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in your browser.

For a smoother development workflow, you can also open the folder in VS
Code and run it with the Live Server extension.
